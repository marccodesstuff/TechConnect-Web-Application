Notes / Next steps:

1. From `web/` run `npm install` (or `pnpm install`) to install all packages.
2. Start dev: `npm run dev` (Vite default on :5173)
3. To finish shadcn integration run: `npx shadcn-ui@latest init` and follow prompts to generate tokens and components.
4. You can add components via: `npx shadcn-ui@latest add <component>` (e.g. `button`, `input`).

MSW (Mock Service Worker): the project includes a mock API under `src/mocks` and the worker starts automatically in development. This lets you work with realistic data without a running backend.
